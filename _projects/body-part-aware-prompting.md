This project explores how body-part-aware prompting can improve the reliability of vision-language models for person re-identification.

The core idea is to guide model attention toward semantically meaningful body regions so the system focuses on identity-relevant cues instead of background correlations or noisy context.

- Proposed a body-part-aware prompting strategy for person re-identification.
- Improved attention localization and robustness in identity matching.
- Accepted to the AWS Machine Learning University AI/ML Student Poster Session 2025.

This work reflects my broader interest in interpretable multimodal systems that align model behavior with the structure of the task.
