This project uses large language models and few-shot prompting to automate risk assessment from social media data.

The goal was to create a scalable workflow that turns unstructured online content into interpretable risk scores across multiple decision areas.

- Designed a scoring framework from 0 to 10.
- Covered financial stability, cybersecurity, and reputation management dimensions.
- Built the pipeline to support analysis at social-media scale.
- Presented the work at the NeurIPS Women in Machine Learning Workshop as an accepted poster.

This project reflects my interest in practical LLM systems that are structured, measurable, and useful in high-stakes domains.
